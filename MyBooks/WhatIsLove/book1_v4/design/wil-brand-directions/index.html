What Is Love? — Four Directions, Light & Dark

Every direction now exists in both modes, shown side by side on identical content so the comparison is honest. The ratio in each header is the measured body-text contrast for that exact variant, computed rather than estimated.

What building the light halves revealed. Two of these did not survive a straight inversion, and that is the useful finding. Sanctuary loses its gold entirely — at 2.1:1 on cream, gold cannot be text, only ornament — so the light variant is a different-feeling design wearing the same colors. Four Pillars needed four genuinely different hues rather than lightened ones, since a color legible on dark stone disappears on light stone. Only Deckle inverts cleanly, which is itself an argument about which one is a real mode pair and which are two designs sharing a palette.
01Sanctuarythe cover, extended into everything else
Burnt Crimson and Gold Torch straight off the cover spec, Cinzel Decorative over Libre Baskerville. The light variant is the harder half and the more interesting one: gold is nearly invisible as text on a pale ground (#be985c on cream is 2.1:1), so it survives only as rules and ornament, and crimson has to carry every label. The result reads less like a gilded page and more like a letterpress title page — arguably closer to what the book actually is.

Where this lands

Seeing all eight together sharpens the earlier point rather than changing it. A mode pair is one design rendered for two lighting conditions; a presentation theme is a different voice. Building the light halves showed which of these is which — and the test was not aesthetic, it was mechanical: does the design survive inversion without being redesigned?

  • Deckle passes cleanly. Same layout, same semantics, same weight in both modes (10.03:1 and 10.53:1). One prefers-color-scheme block, no markup change. This is your default surface.
  • Sanctuary does not. Its light variant is handsome, but it is a second design — gold demoted to ornament, crimson doing all the label work. Keep both as an opt-in presentation theme, invoked by class; don't wire them to a system toggle, because the two halves aren't the same object.
  • Four Pillars is a component in both modes. Two calibrated palettes for diagrams, not two page designs. It should inherit whichever theme is active.
  • Torchlight should probably be dark-only. The dark variant is the better design and avoids the glare problem the gold field has. If you want one gilded thing in the system, make it that.

One thing still unresolved from earlier: the cover spec's subtitle doesn't match the canonical definition. The spec reads "…sacred, sacrificial gift of covenant, binding truth, justice, and mercy…"; the canonical form is "…the sacred gift of covenant which binds truth, justice, mercy and sacrifice…" — no Oxford comma, sacrifice as a fourth co-equal pillar rather than an adjective. Worth fixing before it hardens into the design.
